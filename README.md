# Retina Recall — Diabetic Retinopathy

An interactive, visual study guide built around active recall.

## What is inside

- Interactive schematic fundus with stage selector and clickable lesions
- The 4-2-1 staging builder, including the severe vs very severe distinction
- DME vs PDR management logic and an OCT decision tool
- Screening timeline and red flags
- 20 spaced-repetition flashcards with local scheduling
- 10-question quiz with explanations and saved best score
- One-screen memory palace and teach-back prompt

## Run it

Open `index.html` in a browser. No build step or server is required.

## Notes

This is an educational tool, not medical advice. Images are schematic, not patient photographs. Verify local protocols and current guidelines before clinical use.
